## 調べること

1. **PptxGenJS 4.0.1 の出力に XML を足す方法**
   - `write()` の前後で ZIP の中身（`ppt/slides/slideN.xml` など）を書き換える手段
   - プレースホルダー（`placeholder` オプション）と `defineSlideMaster` で出せるものの範囲
   - 出せないもの（グループ化、アニメーション）を足すときに触る XML の場所
2. **マスターの XML 構造**
   - `ppt/slideMasters/` `ppt/slideLayouts/` `ppt/theme/` の関係と、レイアウトとスライドの参照のされ方
   - 既存の `.pptx` からマスターを取り出して差し替えるのに何が要るか（将来の記録）
3. **Slidev 52.19.1 の書き出し処理**
   - `export` が Playwright でスライドを開く部分のうち、再利用できる関数と、
     アドオン側から呼べるかどうか
   - `slides.md` の解析結果（レイアウト・ノート・クリック数）をどこから取れるか
4. **游ゴシックの扱い**
   - PptxGenJS で和文フォント名を指定したときの XML（`latin` / `ea` の書き分け）
   - PowerPoint がフォントを見つけられないときの代替の挙動

## 成果物

`wip/research/summary.md` に、上の 4 項目ごとに「分かったこと」「設計に効く制約」
「参照した場所（ファイルと行）」を書く。
