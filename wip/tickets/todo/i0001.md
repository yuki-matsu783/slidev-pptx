## 目的

`slides.md` から、PowerPoint 上で文字・表・図形を修正できる PPTX を書き出す。
向きは一方向で、PowerPoint での手直しは Slidev に戻さない。

## 決まっていること

- **部品**: `Ppt` を接頭辞にした Vue 部品（`PptText` `PptShape` `PptImage` `PptTable`）。
  置き場は `packages/slidev-addon-pptx`。`slides.md` から読み込む
- **配置**: 実測配置が既定。Slidev の画面の px で座標指定もできる。
  PPTX へは 16:9（幅 13.333 インチ）へ比例で換算する
- **普通の Markdown**: 見出しはタイトル枠。段落・箇条書き（階層つき）・太字・斜体・
  インラインコード・リンク・引用・表・`::right::` の 2 段組は全部ネイティブ書き出し
- **出せないもの**: コードブロックは等幅のテキスト枠（色付けは捨てる）。数式・Mermaid・
  その他の HTML と Vue は画像への置き換え。置き換えた一覧を書き出しの記録に出す。
  再現できない CSS の装飾は捨てて警告する。`export="image"` で置き換えを指定できる（既定 `native`）
- **マスター**: コードで定義する。レイアウト対応表（`cover` `default` `center` `two-cols`）で
  タイトル枠・本文枠に入れる。表にないレイアウトは位置指定のテキスト枠。
  既存テンプレートへの差し替えは今回やらず、マスターの定義を差し替えられる継ぎ目を 1 か所に切る
- **フォント**: 游ゴシックに統一。Slidev の表示も切り替える
- **クリック要素**: 全部出した状態で 1 枚。アニメーション変換は後の段階
- **生成**: PptxGenJS で組み、足りない分は XML を後から足す。起動は `pnpm export:pptx`
  （Playwright で Slidev を開いて集める）。画像書き出しは `pnpm export:pptx-image` に改名して残す。
  ライトテーマ固定。置き換え画像は 2 倍解像度。URL の画像は取得して埋め込む
- **確かめ方**: 自動は vitest で XML の構造検査。手動は各フェーズのレビューで Windows の
  PowerPoint で開く
- **用語**: `CONTEXT.md`
