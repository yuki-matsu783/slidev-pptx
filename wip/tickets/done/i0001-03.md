## 依存の追加はフェーズ 4 で

このフェーズ（acceptance）の範囲は `tests/*` だけで、`package.json` `pnpm-lock.yaml` `pnpm-workspace.yaml` には
`ask` でも触れない。`vitest`、`@xmldom/xmldom`（未インストール）、直接依存に上げる `jszip` `pptxgenjs`、
`pnpm-workspace.yaml` の `packages: [packages/*]`、`test` `test:e2e` の scripts は、フェーズ 4（implement）の
子チケットの最初の作業にする。acceptance は implement と並行してよい（phases.yml の `overlap`）ので、
フェーズ 4 の子を先に承認して依存だけ入れてもらえば、このチケットの検査をその場で回せる。
それまでは検査ファイルを書くだけで、実行はしない（`gen-pptx.mjs` は PptxGenJS が推移的依存に
あるので `node` で回せる）。

## 決め方

- 検査項目は設計文書の節を引用して書く。設計に無い振る舞いを検査で決めない
- fixture の PPTX は PptxGenJS だけで作り、実装に依存させない
- e2e はアドオン無しで起動するデッキを主にし、部品のデッキはフェーズ 4 まで skip にする
