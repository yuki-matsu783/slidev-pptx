## 成果物

1. `wip/design/native-export.md` — 全体設計
   - 処理の流れ: `pnpm export:pptx` → `resolveOptions(..., 'export')` + `createServer` で
     Slidev を立てる → Playwright で `/print?print=true` を開く → 各スライドの収集結果（JSON）
     → PptxGenJS で組む → 後処理 → 書き出し
   - **後処理で必ず直すもの**: PptxGenJS が重複させる `cNvPr id` / `name`、
     未使用プレースホルダー、実在しないパートへの `[Content_Types].xml` の Override
   - **OPC 整合チェッカ**: python-pptx では検出できない「修復」の原因（重複 id、
     rels の Target、Override）を CI で点検する仕組みの設計
   - **収集結果の形**（ブラウザから Node へ渡す JSON の型）。スライドごとに、レイアウト名・
     ノート・要素の列（種類・位置と大きさ（キャンバス px）・中身・書式・`export` 指定）
   - **後処理の層**: jszip で開いた ZIP に対する、パス指定の XML 変換関数の列。
     未使用プレースホルダーの削除、`[Content_Types].xml` の作り直し、`normAutofit` の
     縮小率、将来のマスター差し替えとプレースホルダー `idx` の付け替えの継ぎ目
   - **レイアウト対応表**: `cover` `default` `center` `two-cols` と PptxGenJS の
     `defineSlideMaster` の定義、タイトル枠・本文枠の位置。表にないレイアウトの扱い
   - **フォント**: 游ゴシックを run ごとに付けるか、テーマに任せるかの決定と理由
   - **座標の換算**: キャンバス px → インチの式と丸め
   - **書き出しの記録**: 画像への置き換え一覧と警告の形式（標準出力とファイル）
   - **CLI**: `export:pptx` の引数、`export:pptx-image` への改名
2. `wip/design/ppt-components.md` — 部品の設計
   - `PptText` `PptShape` `PptImage` `PptTable` の props（座標指定、`export`、書式）と、
     実測配置のときにブラウザで測る方法（`data-ppt-*` 属性か、登録簿か）
   - 普通の Markdown の変換規則（見出し・段落・箇条書きの階層・太字・斜体・インラインコード・
     リンク・引用・表・`::right::`・コードブロック）
   - 画像への置き換えの規則（数式・Mermaid・その他の HTML と Vue）と撮り方（2 倍解像度）
   - 発表者ノートの変換
3. `docs/adr/0001-pptxgenjs-with-xml-patch.md` — 「PptxGenJS で組み、足りない分は
   XML を後から足す。書き出しは一方向」の決定と、退けた代案（XML を全部自前で書く、
   双方向）との比較
